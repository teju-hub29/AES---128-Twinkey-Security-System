# AES---128-Twinkey-Security-System
Developed a hardware-folded FSM architecture routing data through a single AES-128 core twice with inde- pendent 128-bit keys achieving 20-round double-locked encryption with 0.147 W on-chip power and a stable +13.683 ns timing slack. Verified correct encryption, authentication, and decryption across multiple test cases in simulation.
